# 什么是 CrewAI？

**CrewAI 是用于编排自治 AI agents 并构建复杂工作流的领先开源框架。**

它将 **Crews** 的协作智能与 **Flows** 的精细控制结合起来，帮助开发者构建生产可用的多智能体系统。

- **[CrewAI Flows](/zh-CN/guides/flows/first-flow)**：AI 应用的骨架。Flow 让你创建结构化、事件驱动的工作流，管理状态并控制执行，为 agents 提供运行框架。
- **[CrewAI Crews](/zh-CN/guides/crews/first-crew)**：Flow 内的执行单元。Crew 是由自治 agents 组成的团队，协作解决 Flow 委派的特定任务。

已有超过 100,000 名开发者通过我们的社区课程认证，CrewAI 已成为企业级 AI 自动化标准。

## CrewAI 架构

CrewAI 的架构设计在自治能力与可控性之间取得平衡。

### 1. Flows：骨架

<Note>
  可以把 Flow 理解为应用的“管理者”或“流程定义”。它定义步骤、逻辑，以及数据如何在系统内流动。
</Note>

<Frame caption="CrewAI Framework Overview">
  <img src="/images/flows.png" alt="CrewAI Framework Overview" />
</Frame>

Flows 提供：
- **状态管理**：在步骤与执行之间持久化数据。
- **事件驱动执行**：基于事件或外部输入触发动作。
- **控制流**：支持条件逻辑、循环和分支。

### 2. Crews：智能层

<Note>
  Crew 是“真正做事”的团队。在 Flow 中，你可以触发一个 Crew 去处理需要创造力与协作的复杂问题。
</Note>

<Frame caption="CrewAI Framework Overview">
  <img src="/images/crews.png" alt="CrewAI Framework Overview" />
</Frame>

Crews 提供：
- **角色化 Agents**：拥有明确目标和工具的专长 agent。
- **自治协作**：agents 共同完成任务。
- **任务委派**：基于 agent 能力分配与执行任务。

## 它们如何协同工作

1. **Flow** 触发事件或启动流程。
2. **Flow** 管理状态并决定下一步。
3. **Flow** 将复杂任务委派给 **Crew**。
4. **Crew** 内 agents 协作完成任务。
5. **Crew** 将结果返回给 **Flow**。
6. **Flow** 基于结果继续执行。

## 何时使用 Crews 与 Flows

**简短答案：两者都用。**

对于任何生产应用，建议 **先从 Flow 开始**。

- **使用 Flow** 定义应用整体结构、状态与逻辑。
- 在 Flow 的某一步需要自治团队完成复杂任务时，**使用 Crew**。

| Use Case | Architecture |
| :--- | :--- |
| **Simple Automation** | Single Flow with Python tasks |
| **Complex Research** | Flow managing state -> Crew performing research |
| **Application Backend** | Flow handling API requests -> Crew generating content -> Flow saving to DB |

## 为什么选择 CrewAI？

- 🧠 **自治运行**：agents 基于角色与可用工具做出智能决策
- 📝 **自然协作**：agents 像人类团队成员一样沟通协作
- 🛠️ **可扩展设计**：易于增加新工具、角色与能力
- 🚀 **生产可用**：面向真实世界可靠性与可扩展性构建
- 🔒 **安全优先**：按企业安全要求设计
- 💰 **成本高效**：优化 token 使用与 API 调用
