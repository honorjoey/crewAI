## 为您的代理提供用户界面

CrewAI 运行您的代理。 [CopilotKit](https://copilotkit.ai) 为他们提供了一个前端。它们一起让您可以构建应用程序，用户可以在其中与 Crew 或 Flow 聊天、实时观察其工作、批准其决策并查看其输出呈现为实时 UI，而不是文本墙。

两者通过[AG-UI协议](https://docs.ag-ui.com)连接。 `ag-ui-crewai` 包将任何 Crew 或 Flow 作为 AG-UI 端点公开。 CopilotKit 的 React 挂钩和组件使用该端点。这解锁了体验远远超出了聊天框的范围：

渲染代理工具调用和状态为您自己的 React 组件。
 </Card>
 <Card title="人在环（Human-in-the-loop）" icon="user-check" href="/edge/zh-CN/guides/frontend/human-in-the-loop">
在运行中暂停代理以收集用户批准或输入。
 </Card>
 <Card title="共享状态" icon="arrows-rotate" href="/edge/zh-CN/guides/frontend/shared-state">
保持代理状态和您的应用程序 UI 双向同步。
 </Card>
 <Card title="频道" icon="messages" href="/edge/zh-CN/guides/frontend/channels">

本指南让 Crew 或 Flow 与 Next.js 前端进行端到端的对话。本节的其余部分基于您在此处设置的应用程序。

## 架构

一共有三块：

1. **CrewAI 代理服务器**— 通过 AG-UI (FastAPI + `ag-ui-crewai`) 为您的 Crew 或 Flow 提供服务的 Python 进程。
2. **CopilotKit 运行时**— 一个 Next.js 路由，用于注册您的代理并向其代理请求。
3. **React 前端**— `<CopilotKit>` 提供程序加上聊天和生成 UI 组件。

```
React app  ──►  CopilotKit runtime (/api/copilotkit)  ──►  CrewAI server (AG-UI)  ──►  Crew / Flow
```

<Note>
本指南涵盖 **自托管** 路径：您使用 `ag-ui-crewai` 自行运行 CrewAI 代理服务器，并且它在本地运行，无需托管服务。 CopilotKit 还提供**托管** 路径（CopilotKit Cloud / Enterprise具有托管线程和检查器的智能） — 如果您需要的话，请参阅 [CopilotKit CrewAI 快速入门](https://docs.copilotkit.ai/crewai-crews/quickstart)。本节中的前端代码无论哪种方式都是相同的；仅代理的托管方式以及注册的不同。
</Note>

<Note>
CrewAI 以三种形式在 AG-UI 后面运行：常规 **流程**（在这些指南中使用）、**[对话流程](/edge/zh-CN/guides/frontend/conversational-flows)**（本机、会话感知、基于回合、功能齐全）和 **Crews**（基本聊天）。本节中的前端在它们之间是相同的 - 只是后端创作和注册不同。
</Note>

## 集成指南

<Steps>

<Step title="通过 AG-UI 为您的代理提供服务">

将集成包安装到您的 CrewAI 项目中：

```bash
pip install ag-ui-crewai
```

从 FastAPI 应用程序公开您的代理。流程使用 `add_crewai_flow_fastapi_endpoint`；工作人员使用 `add_crewai_crew_fastapi_endpoint`。您可以注册任意多个，每个都在其自己的路径上。

<CodeGroup>

```python Flow
# server.py
from fastapi import FastAPI
from ag_ui_crewai.endpoint import add_crewai_flow_fastapi_endpoint
from my_agents.recipe_flow import RecipeFlow

app = FastAPI(title="CrewAI Agent Server")

add_crewai_flow_fastapi_endpoint(
    app=app,
    flow=RecipeFlow(),
    path="/recipe",
)
```

```python Crew
# server.py
from fastapi import FastAPI
from ag_ui_crewai.endpoint import add_crewai_crew_fastapi_endpoint
from my_agents.research_crew import ResearchCrew

app = FastAPI(title="CrewAI Agent Server")

add_crewai_crew_fastapi_endpoint(
    app=app,
    crew=ResearchCrew().crew(),
    path="/research",
)
```

</CodeGroup>

运行它：

```bash
uvicorn server:app --port 8000
```

<Note>
在启动服务器之前，为您的 LLM 提供商设置环境变量（例如 `OPENAI_API_KEY`）。
</Note>

</Step>

<Step title="创建 Next.js 应用程序">

如果您还没有前端，请搭建一个：

```bash
npx create-next-app@latest my-app
cd my-app
```

安装 CopilotKit 和 CrewAI AG-UI 客户端：

```bash
npm install @copilotkit/react-core @copilotkit/react-ui @copilotkit/runtime @ag-ui/crewai
```

</Step>

<Step title="添加 CopilotKit 运行时">

创建一个向 CopilotKit 运行时注册 CrewAI 代理的路由。每个代理通过 `CrewAIAgent` 指向 Python 服务器上的路径。

```ts
// app/api/copilotkit/route.ts
import {
  CopilotRuntime,
  InMemoryAgentRunner,
  createCopilotEndpoint,
} from "@copilotkit/runtime/v2";
import { CrewAIAgent } from "@ag-ui/crewai";
import { handle } from "hono/vercel";

const runtime = new CopilotRuntime({
  agents: {
    recipe: new CrewAIAgent({ url: "http://localhost:8000/recipe" }),
  },
  runner: new InMemoryAgentRunner(),
});

const app = createCopilotEndpoint({
  runtime,
  basePath: "/api/copilotkit",
});

const handler = handle(app);
export const GET = handler;
export const POST = handler;
```

</Step>

<Step title="使用提供商包装您的应用程序">

将 `<CopilotKit>` 指向运行时路线并命名您注册的代理。

```tsx
// app/page.tsx
"use client";
import { CopilotKit } from "@copilotkit/react-core";
import { CopilotSidebar } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";

export default function Page() {
  return (
    <CopilotKit runtimeUrl="/api/copilotkit" agent="recipe">
      <YourApp />
      <CopilotSidebar agentId="recipe" labels={{ modalHeaderTitle: "Assistant" }} />
    </CopilotKit>
  );
}
```

</Step>

<Step title="运行它">

启动两个进程并打开应用程序。现在，在侧边栏中聊天可以运行您的 Crew 或 Flow。

```bash
uvicorn server:app --port 8000   # terminal 1
npm run dev                       # terminal 2
```

</Step>

</Steps>

## 聊天界面选项

CopilotKit 提供了三个可互换的聊天界面。交换组件；接线是相同的。

<CodeGroup>

```tsx Sidebar
import { CopilotSidebar } from "@copilotkit/react-core/v2";

<CopilotSidebar agentId="recipe" />
```

```tsx Popup
import { CopilotPopup } from "@copilotkit/react-core/v2";

<CopilotPopup agentId="recipe" />
```

```tsx Inline
import { CopilotChat } from "@copilotkit/react-core/v2";

<CopilotChat agentId="recipe" />
```

</CodeGroup>
