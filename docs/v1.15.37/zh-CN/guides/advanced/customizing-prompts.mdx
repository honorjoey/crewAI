## 为什么定制提示 ?

虽然CrewAI的默认会促使许多情景发生时效果良好,但低级定制却打开了显著更灵活和强大的代理行为之门. 这就是为什么你可能想要利用 这个更深的控制:

1. ** 为特定的LLMS做优化** – 不同的模型(如GPT-4,克劳德,或Llama)以适合其独特架构的快速格式蓬勃发展.
2. ** 改变语言** – 建立完全使用英语以外语言的代理,精确处理细微差别.
3. ** 复杂领域的专业化** — 适应高度专业化的行业,如医疗保健、金融或法律行业。
4. ** 只要语气和风格** — — 让代理商更加正式、随意、有创意或分析。
5. ** 支持超定制使用案例** - 利用先进的即时结构和格式,以满足复杂、具体的项目要求。

本指南探索如何在较低层次上挖掘CrewAI的提示,使你能够精细地控制特工们如何思考和互动.

## 了解CrewAI的快速系统

在引擎盖下,CrewAI使用模块化的即时系统,可以广泛定制:

- ** 代理模板 ** – Govern 每个代理对其指定角色的方法.
- **Prompt切片** – 控制任务,工具使用,输出结构等专门行为.
- ** 处理不当** – 代理人如何对故障、例外或超时作出反应。
- ** 具体工具提示** - 界定如何使用工具的详细指示。

请查看 [CrewAI 仓库中的原始提示模板](https://github.com/crewAIInc/crewAI/blob/main/lib/crewai/src/crewai/translations/en.json)，了解这些元素是如何组织的。然后你可以按需覆盖或改造它们，以解锁高级行为。

## 理解默认系统指令

<Warning>
** 生产透明度问题**:CrewAI自动在您的提示中注入你可能不知道的默认指示。 本节解释帽下发生的事情以及如何获得完全控制.
</Warning>

当定义代理人时`role`, `goal`,以及`backstory`, CrewAI 自动添加额外的系统指令,控制格式化和行为. 了解这些默认的注射对于生产系统至关重要,因为在这些生产系统中,你需要完全迅速的透明度。

### CrewAI 自动注入

基于您的代理配置, CrewAI 添加了不同的默认指令 :

#### 没有工具的代理
```text
"I MUST use these formats, my job depends on it!"
```

#### 用于有工具的代理
```text
"IMPORTANT: Use the following format in your response:

Thought: you should always think about what to do
Action: the action to take, only one name of [tool_names]
Action Input: the input to the action, just a simple JSON object...
```

#### 结构化产出(JSON/Pydantic)
```text
"Ensure your final answer contains only the content in the following format: {output_format}
Ensure the final output does not include any code block markers like ```json or ```python."
```

### 查看完整系统提示

查看您的 LLM 正在发送的提示, 您可以检查生成的提示 :

```python
from crewai import Agent, Crew, Task
from crewai.utilities.prompts import Prompts

# Create your agent
agent = Agent(
    role="Data Analyst",
    goal="Analyze data and provide insights",
    backstory="You are an expert data analyst with 10 years of experience.",
    verbose=True
)

# Create a sample task
task = Task(
    description="Analyze the sales data and identify trends",
    expected_output="A detailed analysis with key insights and trends",
    agent=agent
)

# Create the prompt generator
prompt_generator = Prompts(
    agent=agent,
    has_tools=len(agent.tools) > 0,
    use_system_prompt=agent.use_system_prompt
)

# Generate and inspect the actual prompt
generated_prompt = prompt_generator.task_execution()

# Print the complete system prompt that will be sent to the LLM
if "system" in generated_prompt:
    print("=== SYSTEM PROMPT ===")
    print(generated_prompt["system"])
    print("\n=== USER PROMPT ===")
    print(generated_prompt["user"])
else:
    print("=== COMPLETE PROMPT ===")
    print(generated_prompt["prompt"])

# You can also see how the task description gets formatted
print("\n=== TASK CONTEXT ===")
print(f"Task Description: {task.description}")
print(f"Expected Output: {task.expected_output}")
```

### 覆盖默认指令

您有几种选择可以完全控制提示 :

#### 备选案文1:自定义模板(建议)
```python
from crewai import Agent

# Define your own system template without default instructions
custom_system_template = """You are {role}. {backstory}
Your goal is: {goal}

Respond naturally and conversationally. Focus on providing helpful, accurate information."""

custom_prompt_template = """Task: {input}

Please complete this task thoughtfully."""

agent = Agent(
    role="Research Assistant",
    goal="Help users find accurate information",
    backstory="You are a helpful research assistant.",
    system_template=custom_system_template,
    prompt_template=custom_prompt_template,
    use_system_prompt=True  # Use separate system/user messages
)
```

#### 选项2:自定义提示文件
创建一个`custom_prompts.json`覆盖特定提示片的文件 :

```json
{
  "slices": {
    "no_tools": "\nProvide your best answer in a natural, conversational way.",
    "tools": "\nYou have access to these tools: {tools}\n\nUse them when helpful, but respond naturally.",
    "formatted_task_instructions": "Format your response as: {output_format}"
  }
}
```

然后用在你的船员中:

```python
crew = Crew(
    agents=[agent],
    tasks=[task],
    prompt_file="custom_prompts.json",
    verbose=True
)
```

<Note>
`agent.i18n`仅用于向后兼容并作折旧。 对于运行时间即时定制,通过`prompt_file`改为:`Crew`。对于快速切片的程序访问,直接使用 i18n 工具:
</Note>

```python
from crewai.utilities.i18n import get_i18n

i18n = get_i18n("custom_prompts.json")
format_slice = i18n.slice("format")
tool_prompt = i18n.tools("ask_question")
```

#### 备选方案3: O1 型号的禁用系统提示
```python
agent = Agent(
    role="Analyst",
    goal="Analyze data",
    backstory="Expert analyst",
    use_system_prompt=False  # Disables system prompt separation
)
```

## 管理快速文件的最佳做法

在进行低水平的即时定制时,遵循这些准则,以保持事物的组织和可维护性:

1. ** 保持文件分离 ** – 将您的定制提示存储在您主码库外的专用 JSON 文件中.
2. ** Version control** – 存储器内部的跟踪变化,确保有清晰的文件记录随时间推移而迅速调整.
3. ** 按模式或语言组织** - 使用命名方案,例如`prompts_llama.json`或`prompts_es.json`迅速确定专门配置。
4. ** 文件更改** – 提供注释或维持一个读取器,详细说明定制的目的和范围。
5. ** 尽量减少改建** - 只覆盖您真正需要调整的特定切片, 保存默认功能完整地为其它所有 。

## 自定义提示的最简单方式

一个直截了当的方法就是为您想要覆盖的提示创建JSON文件,然后将您的船员指向该文件:

1. 将JSON文件与您更新的提示片一起编译.
2. 通过`prompt_file`参数在您的船员。

然后CrewAI将您的定制与默认合并,所以不需要重新定义每个提示. 是这样的:

将需要直接切片的代码改为:`crewai.utilities.i18n.get_i18n()`使用相同的快捷文件而不是读取`agent.i18n`.

### 示例:基本快速自定义

创建一个`custom_prompts.json`文件带有要修改的提示。 确保您列出它应该包含的所有顶级提示,而不仅仅是您的更改 :

```json
{
  "slices": {
    "format": "When responding, follow this structure:\n\nTHOUGHTS: Your step-by-step thinking\nACTION: Any tool you're using\nRESULT: Your final answer or conclusion"
  }
}
```

然后像这样整合:

```python
from crewai import Agent, Crew, Task, Process

# Create agents and tasks as normal
researcher = Agent(
    role="Research Specialist",
    goal="Find information on quantum computing",
    backstory="You are a quantum physics expert",
    verbose=True
)

research_task = Task(
    description="Research quantum computing applications",
    expected_output="A summary of practical applications",
    agent=researcher
)

# Create a crew with your custom prompt file
crew = Crew(
    agents=[researcher],
    tasks=[research_task],
    prompt_file="path/to/custom_prompts.json",
    verbose=True
)

# Run the crew
result = crew.kickoff()
```

通过这些编辑,您可以获得对代理如何沟通和解决任务的低级控制.

## 优化特定模式

不同的模式在结构不同的提示上蓬勃发展。 做更深层次的调整,可以通过调整你的提示与模型的细微差别,大大提高性能.

### 实例:Llama3.3 提示模板

例如,在处理Meta的Llama 3.3时,更深层次的定制可能反映了下列描述的建议结构:
https://www.llama.com/docs/model-cards-and-prompt-formats/llama3_1/#prompt-template

以下是一个例子来突出你如何微调一个特工 来利用Llama3.3的代码:

```python
from crewai import Agent, Crew, Task, Process
from crewai_tools import DirectoryReadTool, FileReadTool

# Define templates for system, user (prompt), and assistant (response) messages
system_template = """<|begin_of_text|><|start_header_id|>system<|end_header_id|>{{ .System }}<|eot_id|>"""
prompt_template = """<|start_header_id|>user<|end_header_id|>{{ .Prompt }}<|eot_id|>"""
response_template = """<|start_header_id|>assistant<|end_header_id|>{{ .Response }}<|eot_id|>"""

# Create an Agent using Llama-specific layouts
principal_engineer = Agent(
    role="Principal Engineer",
    goal="Oversee AI architecture and make high-level decisions",
    backstory="You are the lead engineer responsible for critical AI systems",
    verbose=True,
    llm="groq/llama-3.3-70b-versatile",  # Using the Llama 3 model
    system_template=system_template,
    prompt_template=prompt_template,
    response_template=response_template,
    tools=[DirectoryReadTool(), FileReadTool()]
)

# Define a sample task
engineering_task = Task(
    description="Review AI implementation files for potential improvements",
    expected_output="A summary of key findings and recommendations",
    agent=principal_engineer
)

# Create a Crew for the task
llama_crew = Crew(
    agents=[principal_engineer],
    tasks=[engineering_task],
    process=Process.sequential,
    verbose=True
)

# Execute the crew
result = llama_crew.kickoff()
print(result.raw)
```

通过这种更深层的配置,你可以对基于Llama的工作流程进行全面的低级别控制,而不需要单独的JSON文件.
