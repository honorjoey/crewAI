## 为什么使用 AGENTS.md

`AGENTS.md` 是一个轻量级的、仓库本地的指令文件，为编码 agent 提供一致的、项目特定的指导。将它放在项目根目录，并将其视为您希望助手如何工作的唯一可信来源：约定、命令、架构说明和防护规则。

## 使用 CLI 创建项目

使用 CrewAI CLI 搭建项目脚手架。`AGENTS.md` 会被添加到根目录，同时还会生成导入它的 `CLAUDE.md` 和 `GEMINI.md`，这样 Claude Code 和 Gemini CLI 就能读取与其他所有助手相同的指导内容。

```bash
# Crew
crewai create crew my_crew

# Flow
crewai create flow my_flow

# Tool repository
crewai create tool my_tool
```

<Note>
 `crewai tool create` 已被弃用，目前仍可使用但会显示警告。请改用 `crewai create tool`。
</Note>

## 工具设置：让助手读取 AGENTS.md

### Codex

Codex 可以通过放置在仓库中的 `AGENTS.md` 文件获得指导。使用这些文件提供持久的项目上下文，例如约定、命令和工作流预期。

### Claude Code

Claude Code 读取 `CLAUDE.md` 而忽略 `AGENTS.md`。脚手架生成的项目附带一个 `CLAUDE.md`，其唯一指令是导入行 `@AGENTS.md`，这样共享指导内容无需重复即可被加载。请在该行下方添加 Claude 特定的说明，并将共享约定保留在 `AGENTS.md` 中。

对于在 `CLAUDE.md` 脚手架功能推出之前创建的项目，请自行添加导入：

```bash
printf '@AGENTS.md\n' > CLAUDE.md
```

不要将 `AGENTS.md` 重命名为 `CLAUDE.md`：Codex 和 Cursor 读取的是 `AGENTS.md`，重命名会使它们无法找到该文件。

### Gemini CLI 和 Google Antigravity

Gemini CLI 和 Antigravity 会从仓库根目录和父目录加载项目上下文文件（默认：`GEMINI.md`）。脚手架生成的项目附带一个 `GEMINI.md`，其唯一指令是导入行 `@./AGENTS.md`，这样共享指导内容无需重复即可被加载。请在该行下方添加 Gemini 特定的说明，并将共享约定保留在 `AGENTS.md` 中。

对于在 `GEMINI.md` 脚手架功能推出之前创建的项目，请自行添加导入：

```bash
printf '@./AGENTS.md\n' > GEMINI.md
```

或者，在 Gemini CLI 设置中将 `context.fileName` 配置为包含 `AGENTS.md`，Gemini 就会直接读取它。不要将 `AGENTS.md` 重命名为 `GEMINI.md`：Codex 和 Cursor 读取的是 `AGENTS.md`，重命名会使它们无法找到该文件。

### Cursor

Cursor 支持将 `AGENTS.md` 作为项目指令文件。将它放在项目根目录，为 Cursor 的编码助手提供指导。

### Windsurf

Claude Code 提供了与 Windsurf 的官方集成。如果您在 Windsurf 中使用 Claude Code，请遵循上面的 Claude Code 指导，并从 `CLAUDE.md` 导入 `AGENTS.md`。

如果您使用的是 Windsurf 的原生助手，请配置其项目规则或指令功能（如果可用）以读取 `AGENTS.md`，或者直接粘贴其内容。
