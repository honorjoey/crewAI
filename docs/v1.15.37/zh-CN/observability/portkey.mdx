<Step title="Configure CrewAI with Portkey">
集成很简单 - 您只需要更新您的 CrewAI 设置中的 LLM 配置 :

```python
from crewai import LLM
from portkey_ai import createHeaders, PORTKEY_GATEWAY_URL

# Create an LLM instance with Portkey integration
gpt_llm = LLM(
    model="gpt-4o",
    base_url=PORTKEY_GATEWAY_URL,
    api_key="dummy",  # We are using a Virtual key, so this is a placeholder
    extra_headers=createHeaders(
        api_key="YOUR_PORTKEY_API_KEY",
        virtual_key="YOUR_LLM_VIRTUAL_KEY",
        trace_id="unique-trace-id",               # Optional, for request tracing
    )
)

#Use them in your Crew Agents like this:

	@agent
	def lead_market_analyst(self) -> Agent:
		return Agent(
			config=self.agents_config['lead_market_analyst'],
			verbose=True,
			memory=False,
			llm=gpt_llm
		)

```

** 什么是虚拟密钥? ** Portkey中的虚拟密钥安全地将您的 LLM 提供者 API 密钥( OpenAI, Anthropic等) 存储在一个加密的金库中. 它们便于关键轮换和预算管理。 [更多关于虚拟密钥在这里](https://portkey.ai/docs/product/ai-gateway/virtual-keys).
</Info>

### 2. 可靠性 - 保持船员顺利运行

在生产中运行船员时,事情可能会出错——API的费率限制,网络问题,或供应商停产. Portkey的可靠性特性确保了你的特工即使在出现问题时也能顺利运行.

在您的 CrewAI 设置中, 使用 Portkey 配置可以简单实现倒置 :

```python
from crewai import LLM
from portkey_ai import createHeaders, PORTKEY_GATEWAY_URL

# Create LLM with fallback configuration
portkey_llm = LLM(
    model="gpt-4o",
    max_tokens=1000,
    base_url=PORTKEY_GATEWAY_URL,
    api_key="dummy",
    extra_headers=createHeaders(
        api_key="YOUR_PORTKEY_API_KEY",
        config={
            "strategy": {
                "mode": "fallback"
            },
            "targets": [
                {
                    "provider": "openai",
                    "api_key": "YOUR_OPENAI_API_KEY",
                    "override_params": {"model": "gpt-4o"}
                },
                {
                    "provider": "anthropic",
                    "api_key": "YOUR_ANTHROPIC_API_KEY",
                    "override_params": {"model": "claude-3-opus-20240229"}
                }
            ]
        }
    )
)

# Use this LLM configuration with your agents
```

如果 GPT-4o 请求失败, 此配置会自动尝试 Claude, 确保您的机组能够继续运行 。

### 4. 安全乘务员的护卫

护卫人员确保你们CrewAI的特工安全行动,并在所有情况下作出适当的反应.

为什么用护栏?

CrewAI代理可以经历各种故障模式:
- 产生有害或不适当的内容
- 泄露像PII这样的敏感信息
- 迷惑错误的信息
- 以不正确格式生成输出

Portkey的护栏增加了对投入和产出的保护.

** 执行护卫设施**

```python
from crewai import Agent, LLM
from portkey_ai import createHeaders, PORTKEY_GATEWAY_URL

# Create LLM with guardrails
portkey_llm = LLM(
    model="gpt-4o",
    base_url=PORTKEY_GATEWAY_URL,
    api_key="dummy",
    extra_headers=createHeaders(
        api_key="YOUR_PORTKEY_API_KEY",
        virtual_key="YOUR_OPENAI_VIRTUAL_KEY",
        config={
            "input_guardrails": ["guardrails-id-xxx", "guardrails-id-yyy"],
            "output_guardrails": ["guardrails-id-zzz"]
        }
    )
)

# Create agent with guardrailed LLM
researcher = Agent(
    role="Senior Research Scientist",
    goal="Discover groundbreaking insights about the assigned topic",
    backstory="You are an expert researcher with deep domain knowledge.",
    verbose=True,
    llm=portkey_llm
)
```

Portkey的护栏可以:
- 在投入和产出中检测和编辑PII
- 过滤有害或不适当的内容
- 对照计划验证响应格式
- 检查幻觉与地面真相
- 应用自定义的商业逻辑和规则

## 为CrewAI建立企业管理

** 为什么是企业治理? **
如果你在组织内使用CrewAI,你需要考虑几个治理方面:
- ** 费用管理**: 控制和跟踪跨团队的AI支出
- ** 准入管制**: 管理哪些团队可以使用特定模式
- ** 用户分析**: 了解整个组织如何使用AI
- ** 安全和合规**:维持企业安全标准
- ** 可靠性**: 确保所有用户提供一致的服务

Portkey增加了一个全面的治理层以满足这些企业需求. 让我们一步一步地实施这些控制.

## 经常问的问题

<AccordionGroup>
  <Accordion title="How does Portkey enhance CrewAI?">
Portkey通过全面的可观察性(追踪,日志,度量衡),可靠性特性(倒置,复刻,缓存)和通过统一的接口访问200+LLMs,为CrewAI增加了生产准备. 这使得调试、优化和扩展您的代理应用程序更加容易。
  </Accordion>

  <Accordion title="Can I use Portkey with existing CrewAI applications?">
对! Portkey与现有的CrewAI应用程序无缝集成. 你只需要用Portkey的版本更新你的LLM配置代码. 其余的特工和船员代码没有改变
  </Accordion>

  <Accordion title="Does Portkey work with all CrewAI features?">
Portkey支持所有CrewAI特性,包括代理,工具,人入工作流程,以及所有任务流程类型(顺序,等级等). 它在不限制框架任何功能的情况下增加了可观察性和可靠性。
  </Accordion>

  <Accordion title="Can I track usage across multiple agents in a crew?">
是的, Portkey 允许您使用一致`trace_id`整个工作流程的追踪 这对于复杂的机组人员特别有用,在那里你想了解跨越多个特工的完全执行路径.
  </Accordion>

  <Accordion title="How do I filter logs and traces for specific crew runs?">
Portkey 允许您添加自定义元数据到您的 LLM 配置中, 然后您可以使用它进行过滤 。 添加字段像`crew_name`, `crew_type`,或`session_id`很容易发现和分析具体船员的死刑。
  </Accordion>

  <Accordion title="Can I use my own API keys with Portkey?">
对! Portkey为各种LLM提供者使用你自己的API密钥. 它安全地把它们存储为虚拟密钥,可以方便地管理和旋转密钥而无需更改代码.
  </Accordion>

</AccordionGroup>
