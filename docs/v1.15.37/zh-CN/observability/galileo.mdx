## 概述

本指南演示如何将 **Galileo** 与 **CrewAI** 集成
用于综合跟踪和评估工程。
在本指南结束时，您将能够追踪您的 CrewAI 代理，
监控他们的表现，并评估他们的行为
伽利略强大的观测平台。

> **什么是伽利略？**[伽利略](https://galileo.ai)是AI评估和可观察性
提供端到端跟踪、评估、
以及人工智能应用的监控。它使团队能够捕捉地面真相，
创建坚固的护栏，并进行系统实验
内置实验跟踪和性能分析——确保可靠性，
透明度以及整个人工智能生命周期的持续改进。

## 入门

本教程遵循[CrewAI 快速入门](/zh-CN/quickstart)并展示了如何添加
伽利略的[CrewAI事件监听器](https://v2docs.galileo.ai/sdk-api/python/reference/handlers/crewai/handler),
一个事件处理程序。
欲了解更多信息，请参阅伽利略的
[将 Galileo 添加到 CrewAI 应用程序](https://v2docs.galileo.ai/how-to-guides/third-party-integrations/add-galileo-to-crewai/add-galileo-to-crewai)
如何指导。

> **注意** 本教程假设您已完成[CrewAI 快速入门](/zh-CN/quickstart).
如果您想要完整的综合示例，请参阅 Galileo
[CrewAI sdk-示例存储库](https://github.com/rungalileo/sdk-examples/tree/main/python/agent/crewAI).

### 第1步：安装依赖项

安装您的应用程序所需的依赖项。
使用您喜欢的方法创建虚拟环境，
然后使用您的在该环境中安装依赖项
首选工具：

```bash
uv add galileo 
```

### 步骤 2：添加到 .env 文件中[CrewAI 快速入门](/zh-CN/quickstart)

```bash
# Your Galileo API key
GALILEO_API_KEY="your-galileo-api-key"

# Your Galileo project name
GALILEO_PROJECT="your-galileo-project-name"

# The name of the Log stream you want to use for logging
GALILEO_LOG_STREAM="your-galileo-log-stream "
```

### 步骤 3：添加 Galileo 事件监听器

要使用 Galileo 启用日志记录，您需要创建一个实例`CrewAIEventListener`.
通过以下方式导入 Galileo CrewAI 处理程序包
在 main.py 文件顶部添加以下代码：

```python
from galileo.handlers.crewai.handler import CrewAIEventListener
```

在 run 函数开始时，创建事件监听器：

```python
def run():
    # Create the event listener
    CrewAIEventListener()
    # The rest of your existing code goes here
```

当您创建侦听器实例时，它会自动
在 CrewAI 注册。

### 第四步：管理你的团队

使用 CrewAI CLI 运行您的团队：

```bash
crewai run
```

### 第五步：在Galileo中查看痕迹

一旦你的工作人员完成，痕迹将被刷新并出现在伽利略中。

## 了解伽利略集成

Galileo 通过注册事件监听器与 CrewAI 集成
捕获 Crew 执行事件（例如代理操作、工具调用、模型响应）
并将它们转发给伽利略进行观测和评估。

### 了解事件监听器

创建一个`CrewAIEventListener()`实例就是全部
为 CrewAI 运行启用 Galileo 所需。实例化后，监听器：

- 自动向 CrewAI 注册
- 从环境变量中读取 Galileo 配置
- 将所有运行数据记录到 Galileo 项目和指定的日志流
  `GALILEO_PROJECT`和`GALILEO_LOG_STREAM`

不需要额外的配置或代码更改。
这次运行的所有数据都记录到伽利略项目中，并且
由您的环境配置指定的日志流
（例如，GALILEO_PROJECT 和 GALILEO_LOG_STREAM）。
