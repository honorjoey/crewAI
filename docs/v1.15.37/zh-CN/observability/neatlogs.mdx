# 简介

Neatlogs 帮助您 **查看代理做了什么**、**为什么**，并 **分享它**。

它捕获每一个步骤：想法、工具调用、响应、评估。没有原始日志。只是清晰、结构化的痕迹。非常适合调试和协作。

## 为什么使用 Neatlogs？

CrewAI 代理使用多种工具和推理步骤。当出现问题时，您需要上下文 - 而不仅仅是错误。

Neatlogs 可以让您：

- 遵循完整的决策路径
- 直接在步骤上添加反馈
- 使用 AI 助手与跟踪对话
- 公开共享运行以获取反馈
- 将见解转化为任务

## 核心功能

- **跟踪查看器**：按顺序跟踪想法、工具和决策
- **内联注释**：在任何跟踪步骤上标记队友
- **反馈和评估**：将输出标记为正确或不正确
- **错误突出显示**：自动标记 API/工具故障
- **任务转换**：将评论转换为分配的任务
- **询问跟踪 (AI)**：使用 Neatlogs AI 机器人与您的跟踪聊天
- **公开共享**：将跟踪链接发布到您的社区

## 使用 CrewAI 进行快速设置

<Steps>
  <Step title="Sign Up & Get API Key">
访问 [整洁日志网站](https://neatlogs.com/?utm_source=crewAI-docs)，创建项目，复制 API 密钥。
  </Step>
  <Step title="Install SDK">
    ```bash
    pip install neatlogs
    ```
（最新版本0.8.0，Python 3.8+；MIT 许可证）
  </Step>
  <Step title="Initialize Neatlogs">
 在启动 Crew 代理之前，添加：

    ```python
    import neatlogs
    neatlogs.init("YOUR_PROJECT_API_KEY")
    ```

 代理照常运行。 Neatlogs 自动捕获所有内容。

  </Step>
</Steps>
