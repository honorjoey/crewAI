# Maxim 概述

Maxim AI 为您的 CrewAI 应用程序提供全面的代理监控、评估和可观察性。借助 Maxim 的单线集成，您可以轻松跟踪和分析座席交互、绩效指标等。

## 功能

### 提示管理

Maxim 的提示管理功能使您能够为 CrewAI 座席创建、组织和优化提示。无需硬编码指令，而是利用 Maxim 的 SDK 动态检索和应用版本控制的提示。

    ## **为什么使用提示比较？**

 即时比较将多个单个提示合并为一个提示视图，为各种工作流程提供简化的方法：

    1. **模型比较**：评估同一提示上不同模型的性能。
    2. **提示优化**：比较提示的不同版本，以确定最有效的配方。
    3. **跨模型一致性**：确保同一提示不同模型的输出一致。
    4. **性能基准测试**：分析指标例如不同模型和提示之间的延迟、成本和令牌计数。

## 入门

### 先决条件


- Python 版本 \>=3.10
- A Maxim 帐户([在这里注册](https://getmaxim.ai/))
- 生成 Maxim API 密钥
- CrewAI 项目

### 安装

通过 pip 安装 Maxim SDK：

```python
pip install maxim-py
```

或将其添加到您的`requirements.txt`：

```
maxim-py
```
### 基本设置

### 1. 设置环境变量

```python
### Environment Variables Setup

# Create a `.env` file in your project root:

# Maxim API Configuration
MAXIM_API_KEY=your_api_key_here
MAXIM_LOG_REPO_ID=your_repo_id_here
```

### 2。导入所需的包

```python
from crewai import Agent, Task, Crew, Process
from maxim import Maxim
from maxim.logger.crewai import instrument_crewai
```

### 3。使用您的 API 密钥


```python {8}
# Instrument CrewAI with just one line
instrument_crewai(Maxim().logger())
```

### 4 初始化 Maxim。像往常一样创建并运行您的 CrewAI 应用程序

```python
# Create your agent
researcher = Agent(
    role='Senior Research Analyst',
    goal='Uncover cutting-edge developments in AI',
    backstory="You are an expert researcher at a tech think tank...",
    verbose=True,
    llm=llm
)

# Define the task
research_task = Task(
    description="Research the latest AI advancements...",
    expected_output="",
    agent=researcher
)

# Configure and run the crew
crew = Crew(
    agents=[researcher],
    tasks=[research_task],
    verbose=True
)

try:
    result = crew.kickoff()
finally:
    maxim.cleanup()  # Ensure cleanup happens even if errors occur
```


就这样\！现在，您所有的 CrewAI 代理交互都将被记录并显示在您的 Maxim 仪表板中。

## 故障排除

### 常见问题

- **未出现任何痕迹**：确保您的 API 密钥和存储库 ID 正确
- 确保您已**`called instrument_crewai()`** **_在_**运行你的团队之前。这将正确初始化日志记录挂钩。
- 在`instrument_crewai()`调用中设置`debug=True`以显示任何内部错误：

  ```python
  instrument_crewai(logger, debug=True)
  ```
- 使用`verbose=True`配置您的代理以捕获详细日志：

  ```python
  agent = CrewAgent(..., verbose=True)
  ```
- 在创建或执行代理之前**仔细检查`instrument_crewai()`是否被调用。这可能是显而易见的，但这是一个常见的疏忽。
