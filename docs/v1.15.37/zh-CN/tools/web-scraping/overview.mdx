## **快速启动示例**

```python
from crewai_tools import ScrapeWebsiteTool, FirecrawlScrapeWebsiteTool, SeleniumScrapingTool

# Create scraping tools
simple_scraper = ScrapeWebsiteTool()
advanced_scraper = FirecrawlScrapeWebsiteTool()
browser_automation = SeleniumScrapingTool()

# Add to your agent
agent = Agent(
    role="Web Research Specialist",
    tools=[simple_scraper, advanced_scraper, browser_automation],
    goal="Extract and analyze web data efficiently"
)
```

## **寻找最佳做法**

- ^ 0: 总是检查和跟踪网站的删除政策
- ^0: 执行请求之间的延迟以避免服务器过多
- "0":使用适当的用户代理字符串来识别您的机器人
- ○ 保证您的刮刮活动符合服务条件
- **处理错误**:对网络问题和被封请求实施有力的错误处理
- **数据质量**:处理前验证和清理提取的数据

## **工具选择指南**

- **简单任务**:使用`ScrapeWebsiteTool` 用于基本内容提取
- **JavaScript- 沉重的站点**:使用`SeleniumScrapingTool` 用于动态内容
- **缩放性能( P)**:使用`FirecrawlScrapeWebsiteTool` 用于大容量刮刮
- **云基础设施**:使用`BrowserBaseLoadTool` 可缩放浏览器自动化
- **复杂工作流程**:使用`StagehandTool` 用于智能浏览器交互
