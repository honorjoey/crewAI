## 安装

通过创建 Oxylabs 账户获取证书 。
```shell
pip install 'crewai[tools]' oxylabs
```
请检查access-date=中的日期值 (帮助) 获取更多关于API参数的信息.

# `OxylabsAmazonProductScraperTool`

### 示例

```python
from crewai_tools import OxylabsAmazonProductScraperTool

# make sure OXYLABS_USERNAME and OXYLABS_PASSWORD variables are set
tool = OxylabsAmazonProductScraperTool()

result = tool.run(query="AAAAABBBBCC")

print(result)
```

### 参数

- `query` - 10 Symbol ASIN代码.
- `domain` - 亚马逊域本地化。
- `geo_location` - 发送到   位置。
- `user_agent_type` - 设备类型和浏览器。
- `render` - 设定到时启用 JavaScript 渲染`html`.
- `callback_url` - URL 到您的召回端点 。
- `context` - 额外的高级设置和特殊要求的控制.
- `parse` - 返回已解析的数据。
- `parsing_instructions` - 定义您自己的解析和数据转换逻辑,该逻辑将在 HTML 切换结果上执行。

### 高级示例

```python
from crewai_tools import OxylabsAmazonProductScraperTool

# make sure OXYLABS_USERNAME and OXYLABS_PASSWORD variables are set
tool = OxylabsAmazonProductScraperTool(
    config={
        "domain": "com",
        "parse": True,
        "context": [
            {
                "key": "autoselect_variant",
                "value": True
            }
        ]
    }
)

result = tool.run(query="AAAAABBBBCC")

print(result)
```

# `OxylabsGoogleSearchScraperTool`

### 示例

```python
from crewai_tools import OxylabsGoogleSearchScraperTool

# make sure OXYLABS_USERNAME and OXYLABS_PASSWORD variables are set
tool = OxylabsGoogleSearchScraperTool()

result = tool.run(query="iPhone 16")

print(result)
```

### 参数

- `query` - 搜索关键字。
- `domain` - Google 域名本地化。
- `start_page` - 开始页码。
- `pages` - 要检索的页数。
- `limit` - 每个页面中要检索的结果数。
- `locale` - `Accept-Language` 更改您的 Google 搜索页面网页界面语言的标题值 。
- `geo_location` - (b) 成果应予调整的地理位置。 正确使用这个参数对于获得正确的数据极为重要.
- `user_agent_type` - 设备类型和浏览器。
- `render` - 设定到时启用 JavaScript 渲染`html`.
- `callback_url` - URL 到您的召回端点 。
- `context` - 额外的高级设置和特殊要求的控制.
- `parse` - 返回已解析的数据。
- `parsing_instructions` - 定义您自己的解析和数据转换逻辑,该逻辑将在 HTML 切换结果上执行。

### 高级示例

```python
from crewai_tools import OxylabsGoogleSearchScraperTool

# make sure OXYLABS_USERNAME and OXYLABS_PASSWORD variables are set
tool = OxylabsGoogleSearchScraperTool(
    config={
        "parse": True,
        "geo_location": "Paris, France",
        "user_agent_type": "tablet",
    }
)

result = tool.run(query="iPhone 16")

print(result)
```

# `OxylabsUniversalScraperTool`

### 示例

```python
from crewai_tools import OxylabsUniversalScraperTool

# make sure OXYLABS_USERNAME and OXYLABS_PASSWORD variables are set
tool = OxylabsUniversalScraperTool()

result = tool.run(url="https://ip.oxylabs.io")

print(result)
```

### 参数

- `url` - 网站url to scrape.
- `user_agent_type` - 设备类型和浏览器。
- `geo_location` - 设置代理服务器的地理定位以获取数据。
- `render` - 设定到时启用 JavaScript 渲染`html`.
- `callback_url` - URL 到您的召回端点 。
- `context` - 额外的高级设置和特殊要求的控制.
- `parse` - 返回已解析后的数据`true`,只要提交 URL 的页面类型存在专用解析器。
- `parsing_instructions` - 定义您自己的解析和数据转换逻辑,该逻辑将在 HTML 切换结果上执行。


### 高级示例

```python
from crewai_tools import OxylabsUniversalScraperTool

# make sure OXYLABS_USERNAME and OXYLABS_PASSWORD variables are set
tool = OxylabsUniversalScraperTool(
    config={
        "render": "html",
        "user_agent_type": "mobile",
        "context": [
            {"key": "force_headers", "value": True},
            {"key": "force_cookies", "value": True},
            {
                "key": "headers",
                "value": {
                    "Custom-Header-Name": "custom header content",
                },
            },
            {
                "key": "cookies",
                "value": [
                    {"key": "NID", "value": "1234567890"},
                    {"key": "1P JAR", "value": "0987654321"},
                ],
            },
            {"key": "http_method", "value": "get"},
            {"key": "follow_redirects", "value": True},
            {"key": "successful_status_codes", "value": [808, 909]},
        ],
    }
)

result = tool.run(url="https://ip.oxylabs.io")

print(result)
```
