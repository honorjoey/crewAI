# `BrowserbaseLoadTool`

## 说明

"0"是一个可以可靠运行,管理,监控无头浏览器的开发者平台.

为您的 AI 数据检索提供动力 :

 - 提供可靠浏览器从复杂的UIs提取数据
 - 包括指纹和自动查查解
 - 用网络时间和日志检查浏览器会话
 - 快速调试您的自动化

## 安装

- 从“ 0” 获取一个 API 密钥和项目 ID, 并将其设置在环境变量中( )`BROWSERBASE_API_KEY`, `BROWSERBASE_PROJECT_ID`).
- 随“ 0” 一起安装`crewai[tools]` 软件包 :

```shell
pip install browserbase 'crewai[tools]'
```

## 示例

使用浏览器LoadToole 如下, 您的代理机可以加载网站 :

```python Code
from crewai_tools import BrowserbaseLoadTool

# Initialize the tool with the Browserbase API key and Project ID
tool = BrowserbaseLoadTool()
```

## 参数

下列参数可用于自定义`BrowserbaseLoadTool`'行为 :

| 参数| 类型| 说明|
|:---------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------|
| **键**    | `弦 '|  可选 . 浏览器库 API 密钥 。 默认为 `BROWSERBASE API KEY' env 变量。|
| **工程编号** | `弦 '|  可选 . 浏览器项目 ID. 默认为 `BROWSERBASE PROJECT ID' env 变量。|
| **文本内容( C)** | `波尔'|  可选 . 只获取文本内容 。 默认为`虚假'。|
| **会话( D)** | `弦 '|  可选 . 提供现有的会话标识 。|
| **代理服务器**      | `波尔'|  optional . 启用/禁用代理 。 默认为`虚假'。|
