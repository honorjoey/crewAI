# `ScrapflyScrapeWebsiteTool`

## 说明

那个`ScrapflyScrapeWebsiteTool` 以获取网站内容。 这个工具提供了先进的网页刮擦能力,具有无头浏览器支持,代理,以及反机器人绕行功能. 它允许以各种格式提取网页数据,包括原始的HTML,markdown,和纯文本,使得它对于广泛的网页刮切任务来说是理想的.

## 安装

要使用此工具, 您需要安装 Scrapfly SDK :

```shell
uv add scrapfly-sdk
```

您还需要通过在"0"注册获得 Scrapfly API 密钥.

## 开始的步骤

有效利用`ScrapflyScrapeWebsiteTool`,遵循这些步骤:

1. "0":使用上面的命令安装Scrapfly SDK.
2. 在Scrapfly注册以获取你的API密钥。
3. "0":用您的 API 密钥创建工具实例 。
4. “0”:根据您的需要自定义删除参数。

## 示例

以下例子说明如何使用`ScrapflyScrapeWebsiteTool` 从网站上提取内容:

```python Code
from crewai import Agent, Task, Crew
from crewai_tools import ScrapflyScrapeWebsiteTool

# Initialize the tool
scrape_tool = ScrapflyScrapeWebsiteTool(api_key="your_scrapfly_api_key")

# Define an agent that uses the tool
web_scraper_agent = Agent(
    role="Web Scraper",
    goal="Extract information from websites",
    backstory="An expert in web scraping who can extract content from any website.",
    tools=[scrape_tool],
    verbose=True,
)

# Example task to extract content from a website
scrape_task = Task(
    description="Extract the main content from the product page at https://web-scraping.dev/products and summarize the available products.",
    expected_output="A summary of the products available on the website.",
    agent=web_scraper_agent,
)

# Create and run the crew
crew = Crew(agents=[web_scraper_agent], tasks=[scrape_task])
result = crew.kickoff()
```

## 参数

那个`ScrapflyScrapeWebsiteTool` 接受以下参数:

### 初始化参数

- 需要吗? 你的Scrapfly API密钥。

### 运行参数

- 需要吗? 要刮掉的网站的 URL 。
- 零:可选。 提取网页内容的格式 。 选项为"raw"(HTML),"markdown",或"text". 默认为"markdown".
- 零:可选。 包含额外Scrapfly刮刮配置选项的词典 。
- 零:可选。 刮刮时是否忽略故障 。 如果设置为`True`,工具将返回`None` 而不是在刮刮失败时提出例外。

## 碎飞配置选项

那个`scrape_config` 参数允许您以下列选项自定义刮切行为:

- "0":启用防刮保护绕道.
- "0":启用 JavaScript 无云头浏览器渲染.
- =0=: 选择一个代理池(例如“public rematical pool”,“数据中心”) 。
- **国家**:选择一个代理位置(如"us","uk").
- "0":自动滚动页面来装入懒惰内容.
- \0\:由无头浏览器执行自定义 JavaScript 代码 。

关于完整的配置选项清单,请参见“0” 。

## 处理错误

默认情况下,`ScrapflyScrapeWebsiteTool` 如果刮伤失败, 将提出例外 。 可以指示特工们通过具体说明`ignore_scrape_failures` 参数 :

```python Code
# Create a task that instructs the agent to handle errors
error_handling_task = Task(
    description="""
    Extract content from a potentially problematic website and make sure to handle any 
    scraping failures gracefully by setting ignore_scrape_failures to True.
    """,
    expected_output="Either the extracted content or a graceful error message",
    agent=web_scraper_agent,
)
```

## 执行详情

那个`ScrapflyScrapeWebsiteTool` 使用Scrapfly SDK与Scrapfly API交互:

```python Code
class ScrapflyScrapeWebsiteTool(BaseTool):
    name: str = "Scrapfly web scraping API tool"
    description: str = (
        "Scrape a webpage url using Scrapfly and return its content as markdown or text"
    )
    
    # Implementation details...
    
    def _run(
        self,
        url: str,
        scrape_format: str = "markdown",
        scrape_config: Optional[Dict[str, Any]] = None,
        ignore_scrape_failures: Optional[bool] = None,
    ):
        from scrapfly import ScrapeApiResponse, ScrapeConfig

        scrape_config = scrape_config if scrape_config is not None else {}
        try:
            response: ScrapeApiResponse = self.scrapfly.scrape(
                ScrapeConfig(url, format=scrape_format, **scrape_config)
            )
            return response.scrape_result["content"]
        except Exception as e:
            if ignore_scrape_failures:
                logger.error(f"Error fetching data from {url}, exception: {e}")
                return None
            else:
                raise e
```
