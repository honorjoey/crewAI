# `ApifyActorsTool`

将 [演员表](https://apify.com/actors) 集成到您的 CrewAI 工作流程中。

## 描述

这`ApifyActorsTool` 将[演员表](https://apify.com/actors)（用于网络抓取和自动化的基于云的程序）连接到您的 CrewAI 工作流程。
使用 [Apify商店](https://apify.com/store) 上 4,000 多个参与者中的任何一个来处理用例，例如从社交媒体、搜索引擎、在线地图、电子商务网站、旅游门户或一般网站提取数据。

有关详细信息，请参阅 Apify 文档中的[Apify CrewAI 集成](https://docs.apify.com/platform/integrations/crewai)。

## 开始步骤

<Steps>
    <Step title="安装依赖项">
        安装`crewai[tools]` 和`langchain-apify` 使用点：`pip install 'crewai[tools]' langchain-apify`.
    </Step>
    <Step title="获取 Apify API 令牌">
        注册 [Apify控制台](https://console.apify.com/) 并获取 [Apify API 令牌](https://console.apify.com/settings/integrations)..
    </Step>
    <Step title="配置环境">
        将您的 Apify API 令牌设置为`APIFY_API_TOKEN` 环境变量来启用该工具的功能。
    </Step>
</Steps>

## 使用示例

使用`ApifyActorsTool` 手动运行[RAG 网络浏览器演员](https://apify.com/apify/rag-web-browser)来执行网络搜索：

```python
from crewai_tools import ApifyActorsTool

# Initialize the tool with an Apify Actor
tool = ApifyActorsTool(actor_name="apify/rag-web-browser")

# Run the tool with input parameters
results = tool.run(run_input={"query": "What is CrewAI?", "maxResults": 5})

# Process the results
for result in results:
    print(f"URL: {result['metadata']['url']}")
    print(f"Content: {result.get('markdown', 'N/A')[:100]}...")
```

### 预期产出

这是运行上面代码的输出：

```text
URL: https://www.example.com/crewai-intro
Content: CrewAI is a framework for building AI-powered workflows...
URL: https://docs.crewai.com/
Content: Official documentation for CrewAI...
```

这`ApifyActorsTool` 使用提供的自动从 Apify 获取 Actor 定义和输入模式`actor_name` 然后构建工具描述和论证模式。这意味着您只需指定一个有效的`actor_name`，当与代理一起使用时，该工具会处理其余的事情 - 无需指定`run_input`。它的工作原理如下：

```python
from crewai import Agent
from crewai_tools import ApifyActorsTool

rag_browser = ApifyActorsTool(actor_name="apify/rag-web-browser")

agent = Agent(
    role="Research Analyst",
    goal="Find and summarize information about specific topics",
    backstory="You are an experienced researcher with attention to detail",
    tools=[rag_browser],
)
```

您只需更改 [Apify商店](https://apify.com/store) 即可运行其他 Actor`actor_name` 并且，手动使用时，调整`run_input` 基于 Actor 输入模式。

有关代理的使用示例，请参阅[CrewAI 演员模板](https://apify.com/templates/python-crewai)。

## 配置

这`ApifyActorsTool` 需要这些输入才能工作：

- **`actor_name`**
  要运行的 Apify Actor 的 ID，例如，`"apify/rag-web-browser"`。浏览[Apify商店](https://apify.com/store)上的所有演员。
- **`run_input`**
  手动运行工具时 Actor 的输入参数字典。
  - 例如，对于`apify/rag-web-browser` 演员：`{"query": "search term", "maxResults": 5}`
  - 有关输入参数列表，请参阅 Actor 的[输入模式](https://apify.com/apify/rag-web-browser/input-schema)。
