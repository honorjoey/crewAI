## **常见用例**

- **内容生成**：创建图像、文本和多媒体内容
- **数据分析**：执行代码并分析复杂的数据集
- **知识系统**：构建RAG系统和智能数据库
- **计算机视觉**：处理和理解视觉内容
- **人工智能安全**：实施内容审核和安全检查

```python
from crewai_tools import DallETool, VisionTool

# Create AI tools
image_generator = DallETool()
vision_processor = VisionTool()

# Add to your agent
agent = Agent(
    role="AI Specialist",
    tools=[image_generator, vision_processor],
    goal="Create and analyze content using AI capabilities"
)
