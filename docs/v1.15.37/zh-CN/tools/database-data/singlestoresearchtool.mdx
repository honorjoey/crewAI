# `SingleStoreSearchTool`

## 描述

执行只读查询（`SELECT`/`SHOW`）针对具有连接池和输入验证的 SingleStore。

## 安装

```shell
uv add crewai-tools[singlestore]
```

## 环境变量

变量如`SINGLESTOREDB_HOST`, `SINGLESTOREDB_USER`, `SINGLESTOREDB_PASSWORD`等，可以使用，或者`SINGLESTOREDB_URL` 作为单个 DSN。

从 SingleStore 仪表板生成 API 密钥，[文档在这里](https://docs.singlestore.com/cloud/reference/management-api/#generate-an-api-key)。

## 例子

```python Code
from crewai import Agent, Task, Crew
from crewai_tools import SingleStoreSearchTool

tool = SingleStoreSearchTool(
    tables=["products"], 
    host="host", 
    user="user", 
    password="pass", 
    database="db",
)

agent = Agent(
    role="Analyst", 
    goal="Query SingleStore", 
    tools=[tool], 
    verbose=True,
)

task = Task(
    description="List 5 products", 
    expected_output="5 rows as JSON/text", 
    agent=agent,
)

crew = Crew(
    agents=[agent], 
    tasks=[task],
    verbose=True,
)

result = crew.kickoff()
```
