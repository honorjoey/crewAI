# `DB2VectorSearchTool`

## 描述

使用本机对 IBM Db2 表执行语义向量相似性搜索`VECTOR_DISTANCE` 功能。
支持可配置的距离度量、OpenAI 或自定义嵌入、元数据过滤和结果整形。

## 安装

```bash
pip install ibm_db openai
```

或者用紫外线：

```bash
uv add ibm_db openai
```

## 环境变量

```bash
OPENAI_API_KEY=your_openai_key          # Required when using default OpenAI embeddings
DB2_CONNECTION_STRING=DATABASE=TESTDB;HOSTNAME=localhost;PORT=50000;PROTOCOL=TCPIP;UID=db2user;PWD=password;
```

## 基本用法

```python
from crewai import Agent
from crewai_tools import DB2VectorSearchTool

tool = DB2VectorSearchTool(
    connection_string="DATABASE=TESTDB;HOSTNAME=localhost;PORT=50000;PROTOCOL=TCPIP;UID=db2user;PWD=password;",
    table_name="documents",
    vector_column="embedding",
)

agent = Agent(
    role="Research Assistant",
    goal="Find relevant information in documents",
    tools=[tool],
)
```

## 完整的语义搜索工作流程

```python
import os
from dotenv import load_dotenv
from crewai import Agent, Task, Crew, Process
from crewai_tools import DB2VectorSearchTool

load_dotenv()

db2_tool = DB2VectorSearchTool(
    connection_string=os.getenv("DB2_CONNECTION_STRING"),
    table_name="documents",
    vector_column="embedding",
    return_columns=["content", "category"],
    limit=3,
    distance_metric="COSINE",
    max_distance=0.35,
)

search_agent = Agent(
    role="Senior Semantic Search Agent",
    goal="Find and analyse documents based on semantic search",
    backstory="You are an expert research assistant who can find relevant information using semantic search in a Db2 database.",
    tools=[db2_tool],
    verbose=True,
)

answer_agent = Agent(
    role="Senior Answer Assistant",
    goal="Generate answers based on retrieved context",
    backstory="You are an expert assistant who generates answers from provided context.",
    tools=[db2_tool],
    verbose=True,
)

search_task = Task(
    description="""Search for relevant documents about {query}.
    Include the relevant information found, vector distances, and returned fields.""",
    agent=search_agent,
)

answer_task = Task(
    description="Given the retrieved Db2 context, generate a final answer.",
    agent=answer_agent,
)

crew = Crew(
    agents=[search_agent, answer_agent],
    tasks=[search_task, answer_task],
    process=Process.sequential,
    verbose=True,
)

result = crew.kickoff(inputs={"query": "What is the role of X in the document?"})
print(result)
```

## 工具参数

| 范围| 类型| 默认| 描述|
|---|---|---|---|
| `连接字符串`| `str`| 必需的| Db2 连接字符串。格式：`DATABASE=x;HOSTNAME=x;PORT=50000;PROTOCOL=TCPIP;UID=x;PWD=x;`|
| `表名`| `str`| `“文件”`| 要搜索的表。支持“schema.table”表示法。|
| `向量列`| `str`| `“嵌入”`| 存储向量嵌入的列。|
| `嵌入模型`| `str`| `“文本嵌入-3-大”`| 未提供自定义嵌入功能时使用的 OpenAI 模型。|
| `返回列`| `列表[字符串]`| `[“内容”]`| 每个结果中包含的列。必须包含至少一个条目。|
| `限制`| `int`| `3` | 最大结果数 (1–100)。|
| `距离度量`| `str`| `“余弦”`| Db2 距离度量。请参阅下面支持的值。|
| `最大距离`| `浮动\| 无`| `无`| 丢弃距离超过该值的结果。|
| `custom_embedding_fn`| `可调用[[str]，列表[float]] \| 无`| `无`| 自定义嵌入功能。如果提供，则覆盖 OpenAI。|

## 支持的距离指标

以下值直接映射到 Db2`VECTOR_DISTANCE` 功能：

- `COSINE`
- `EUCLIDEAN`
- `EUCLIDEAN_SQUARED`
- `DOT`
- `HAMMING`
- `MANHATTAN`

参考：[IBM Db2 VECTOR_DISTANCE 文档](https://www.ibm.com/docs/zh-CN/db2/12.1.x?topic=functions-vector-distance)

## 架构参数（每个查询）

| 范围| 类型| 必需的| 描述|
|---|---|---|---|
| `查询`| `str`| ✅ | 搜索查询。|
| `过滤依据`| `str \| 无`| ❌ | 用于元数据过滤的列名称。必须与“filter_value”配对。|
| `过滤器值`| `任何\| 无`| ❌ | 要过滤的值。必须与“filter_by”配对。|

## 返回格式

```json
{
  "success": true,
  "results": [
    {
      "distance": 0.1401,
      "data": {
        "content": "Document content here",
        "category": "research"
      }
    }
  ]
}
```

出错时：

```json
{
  "success": false,
  "error": "Description of what went wrong",
  "error_type": "ExceptionClassName"
}
```

## 元数据过滤

```python
result = db2_tool.run(
    query="machine learning",
    filter_by="category",
    filter_value="research",
)
```

`filter_by` 和`filter_value` 必须始终一起提供。仅提供一个会引发验证错误。

## 定制嵌入

通过提供一个来使用任何嵌入模型`custom_embedding_fn`:

```python
from sentence_transformers import SentenceTransformer
from crewai_tools import DB2VectorSearchTool

model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

def custom_embeddings(text: str) -> list[float]:
    return model.encode(text).tolist()

tool = DB2VectorSearchTool(
    connection_string="DATABASE=TESTDB;HOSTNAME=localhost;PORT=50000;PROTOCOL=TCPIP;UID=db2user;PWD=password;",
    table_name="documents",
    custom_embedding_fn=custom_embeddings,
)
```

什么时候`custom_embedding_fn` 提供，`OPENAI_API_KEY` 不是必需的。

## 安全特性

- SQL 标识符验证（表、列名称必须匹配`^[A-Za-z][A-Za-z0-9_]*(\.[A-Za-z][A-Za-z0-9_]*)?$`)
- 参数化 SQL 查询 — 值从未插入到 SQL 字符串中
- 距离度量白名单 — 仅接受有效的 Db2 度量名称
