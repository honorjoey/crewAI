# `SerpApiGoogleSearchTool`

## 说明

使用`SerpApiGoogleSearchTool` 用 SerpApi 运行 Google 搜索并获取结构化结果。 需要 SerpApi API 密钥 。

## 安装

```shell
uv add crewai-tools[serpapi]
```

## 环境变量

- `SERPAPI_API_KEY` (需要):用于SerpApi的API密钥. 在https://serpapi.com/上创建一个(可自由分级)。

## 示例

```python Code
from crewai import Agent, Task, Crew
from crewai_tools import SerpApiGoogleSearchTool

tool = SerpApiGoogleSearchTool()

agent = Agent(
    role="Researcher",
    goal="Answer questions using Google search",
    backstory="Search specialist",
    tools=[tool],
    verbose=True,
)

task = Task(
    description="Search for the latest CrewAI releases",
    expected_output="A concise list of relevant results with titles and links",
    agent=agent,
)

crew = Crew(agents=[agent], tasks=[task])
result = crew.kickoff()
```

## 页:1

- 设定`SERPAPI_API_KEY` 在环境中。 在 https://serpapi.com/ 创建密钥
- 请参看Google通过SerpApi购物:`/zh-CN/tools/search-research/serpapi-googleshoppingtool`

## 参数

### 运行参数

- `search_query` (str, required):谷歌查询.
- `location` (str,可选):地理位置参数.

## 页:1

- 此工具将 SerpApi 包裹起来并返回结构化搜索结果 。
