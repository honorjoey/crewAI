# `GithubSearchTool`

<Note>
    我们仍然在努力改进工具,所以将来可能会有出乎意料的行为或变化.
</Note>

## 说明

GithubSearchToole是一个 Retrival-Augmented Generation (RAG) 工具,专门用于在GitHub寄存器内进行语义搜索. 它利用先进的语义搜索能力,通过代码、调用请求、问题和寄存器进行筛选,使其成为开发者、研究人员或需要GitHub提供准确信息的人的基本工具。

## 安装

要使用 GithubSearch Tool, 首先要确保在您的 Python 环境中安装 coperai tools 软件包 :

```shell
pip install 'crewai[tools]'
```

此命令会安装运行 GithubSearchTool 的必要软件包, 以及包含在 gegerai tools 软件包中的任何其他工具 。

在 https://github.com/settings/tokens 上获取 GitHub 个人访问功能 (开发者设置 ~ Fine  grained or classics).

## 示例

以下是您如何使用 GithubSearch Tool 在 GitHub 仓库内进行语义搜索 :

```python Code
from crewai_tools import GithubSearchTool

# Initialize the tool for semantic searches within a specific GitHub repository
tool = GithubSearchTool(
	github_repo='https://github.com/example/repo',
	gh_token='your_github_personal_access_token',
	content_types=['code', 'issue'] # Options: code, repo, pr, issue
)

# OR

# Initialize the tool for semantic searches within a specific GitHub repository, so the agent can search any repository if it learns about during its execution
tool = GithubSearchTool(
	gh_token='your_github_personal_access_token',
	content_types=['code', 'issue'] # Options: code, repo, pr, issue
)
```

## 参数

- `github_repo` : 将进行搜索的 GitHub 仓库的 URL 。 这是一个强制字段,并指定您搜索的目标寄存器 。
- `gh_token` : 您的 GitHub 个人访问 Token( PAT) 认证需要 。 您可以在开发者设置 > Personal Access Tokens 下的 GitHub 账户设置中创建一个。
- `content_types` : 指定搜索中要包含的内容类型。 您必须提供来自以下选项的内容类型列表:`code` 在代码内搜索,
`repo` 在存储库的一般信息中搜索,`pr` 在拉动请求中搜索,以及`issue` 在问题中搜索。
这个字段是强制性的,并允许根据GitHub寄存器内的特定内容类型进行搜索.

## 自定义模式和嵌入

默认情况下,该工具同时使用OpenAI进行嵌入和概括. 要自定义模型,可以使用配置词典如下:

```python Code
tool = GithubSearchTool(
    config=dict(
        llm=dict(
            provider="ollama", # or google, openai, anthropic, llama2, ...
            config=dict(
                model="llama2",
                # temperature=0.5,
                # top_p=1,
                # stream=true,
            ),
        ),
        embedder=dict(
            provider="google-generativeai", # or openai, ollama, ...
            config=dict(
                model_name="gemini-embedding-001",
                task_type="RETRIEVAL_DOCUMENT",
                # title="Embeddings",
            ),
        ),
    )
)
