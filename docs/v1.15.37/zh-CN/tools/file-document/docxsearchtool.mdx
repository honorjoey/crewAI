# `DOCXSearchTool`

<Note>
    我们仍然在努力改进工具,所以将来可能会有出乎意料的行为或变化.
</Note>

## 说明

那个`DOCXSearchTool` 是一种RAG工具,用于在DOCX文档中进行语义搜索。
它使用户能够通过基于查询的搜索,有效地搜索和提取DOCX文件中的相关信息.
这一工具对于数据分析、信息管理和研究任务十分宝贵。
简化在大型文件收集中查找具体信息的程序。

## 安装

通过在终端运行以下命令来安装乘务员 工具包:

```shell
uv pip install docx2txt 'crewai[tools]'
```

## 示例

以下示例显示, DOCXSearchTool 初始化可搜索到任何 DOCX 文件的内容或带有特定的 DOCX 文件路径 。

```python Code
from crewai_tools import DOCXSearchTool

# Initialize the tool to search within any DOCX file's content
tool = DOCXSearchTool()

# OR

# Initialize the tool with a specific DOCX file, 
# so the agent can only search the content of the specified DOCX file
tool = DOCXSearchTool(docx='path/to/your/document.docx')
```

## 参数

下列参数可用于自定义`DOCXSearchTool`'行为 :

| 参数| 类型| 说明|
|:---------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------|
| **docx 文档**        | `弦 '|  可选 . 指定您要搜索的 DOCX 文件路径的参数 。 如果初始化期间没有提供,该工具允许以后对任何DOCX文件的内容路径进行规格化搜索.|

## 自定义模式和嵌入

默认情况下,该工具同时使用OpenAI进行嵌入和概括. 要自定义模型,可以使用配置词典如下:

```python Code
from chromadb.config import Settings

tool = DOCXSearchTool(
    config={
        "embedding_model": {
            "provider": "openai",
            "config": {
                "model": "text-embedding-3-small",
                # "api_key": "sk-...",
            },
        },
        "vectordb": {
            "provider": "chromadb",  # or "qdrant"
            "config": {
                # "settings": Settings(persist_directory="/content/chroma", allow_reset=True, is_persistent=True),
                # from qdrant_client.models import VectorParams, Distance
                # "vectors_config": VectorParams(size=384, distance=Distance.COSINE),
            }
        },
    }
)
```
