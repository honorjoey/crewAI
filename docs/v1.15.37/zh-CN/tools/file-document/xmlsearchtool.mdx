# `XMLSearchTool`

<Note>
    我们仍然在努力改进工具,所以将来可能会有出乎意料的行为或变化.
</Note>

## 说明

XMLSearchToole是一个为在XML文件内进行语义搜索而设计的前沿RAG工具.
对于需要高效解析和提取XML内容信息的用户来说理想,这个工具支持输入搜索查询和可选的XML文件路径.
通过指定一个XML路径,用户可以更精确地将其搜索瞄准该文件的内容,从而获得更多的相关搜索结果.

## 安装

要开始使用XMLSearchToole,您必须首先安装createai tools软件包. 这很容易用以下命令完成:

```shell
pip install 'crewai[tools]'
```

## 示例

以下是两个实例,说明如何使用XMLSearch Tool.
第一个例子显示在特定的XML文件中进行搜索,而第二个例子说明启动搜索时没有预先定义XML路径,为搜索范围提供了灵活性.

```python Code
from crewai_tools import XMLSearchTool

# Allow agents to search within any XML file's content 
#as it learns about their paths during execution
tool = XMLSearchTool()

# OR

# Initialize the tool with a specific XML file path 
#for exclusive search within that document
tool = XMLSearchTool(xml='path/to/your/xmlfile.xml')
```

## 参数

- `xml`: 这是您想要搜索的 XML 文件的路径 。
它是该工具初始化期间的可选参数,但必须在初始化时提供,或作为该工具的一部分提供。`run` 用于执行搜索的方法参数。

## 自定义模式和嵌入

默认情况下,该工具同时使用OpenAI进行嵌入和概括. 要自定义模型,可以使用配置词典如下:

```python Code  
from chromadb.config import Settings

tool = XMLSearchTool(
    config={
        "embedding_model": {
            "provider": "openai",
            "config": {
                "model": "text-embedding-3-small",
                # "api_key": "sk-...",
            },
        },
        "vectordb": {
            "provider": "chromadb",  # or "qdrant"
            "config": {
                # "settings": Settings(persist_directory="/content/chroma", allow_reset=True, is_persistent=True),
                # from qdrant_client.models import VectorParams, Distance
                # "vectors_config": VectorParams(size=384, distance=Distance.COSINE),
            }
        },
    }
)
```
