## 介绍

CrewAI 提供了重播最近一次船员启动时指定的任务的能力。当您完成启动并且可能想要重试某些任务或不需要重新获取数据并且您的代理已经保存了启动执行中的上下文时，此功能特别有用，因此您只需重播您想要的任务。

<Note>
您必须先运行`crew.kickoff()`，然后才能重播任务。
目前，仅支持最新的开球，因此如果您使用`kickoff_for_each`，它将只允许您从最近的团队运行中重播。
</Note>

以下是如何重播任务的示例：

### 使用 CLI 重播特定任务

要使用重播功能，请按照下列步骤操作：

<Steps>
   <Step title="Open your terminal or command prompt."></Step>
   <Step title="Navigate to the directory where your CrewAI project is located."></Step>
   <Step title="Run the following commands:">
要查看最新的启动任务 ID，请使用：

      ```shell
      crewai log-tasks-outputs
      ```

一旦你有了`task_id`来重播，请使用：

      ```shell
      crewai replay -t <task_id>
      ```
   </Step>
</Steps>

<Note>
确保在您的开发环境中正确安装和配置`crewai`。
</Note>

### 以编程方式重播任务

要以编程方式重播任务，请使用以下步骤：

<Steps>
   <Step title="Specify the `task_id` and input parameters for the replay process.">
指定`task_id` 和重播过程的输入参数。
   </Step>
   <Step title="Execute the replay command within a try-except block to handle potential errors.">
在 try- except 块中执行重放命令以处理潜在的错误。
      <CodeGroup>
          ```python Code
            def replay():
            """
            Replay the crew execution from a specific task.
            """
            task_id = '<task_id>'
            inputs = {"topic": "CrewAI Training"}  # This is optional; you can pass in the inputs you want to replay; otherwise, it uses the previous kickoff's inputs.
            try:
                YourCrewName_Crew().crew().replay(task_id=task_id, inputs=inputs)

            except subprocess.CalledProcessError as e:
                raise Exception(f"An error occurred while replaying the crew: {e}")

            except Exception as e:
                raise Exception(f"An unexpected error occurred: {e}")
            ```
      </CodeGroup>
   </Step>
</Steps>
