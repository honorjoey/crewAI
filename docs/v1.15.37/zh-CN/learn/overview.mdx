## 学习路径建议

### 对于初学者
1. 从**顺序流程**开始了解基本工作流程执行
2. 了解**自定义代理**以创建有效的代理配置
3. 探索**创建自定义工具**以扩展功能
4. 尝试 **人在环（Human in the Loop）** 进行交互式工作流程

### 对于中级用户
1. 掌握复杂多代理系统的**分层流程**
2. 为动态工作流程实施**条件任务**
3. 使用**异步启动**进行性能优化
4. 集成针对专业模型的**定制 LLM**

### 对于高级用户
1. 构建用于复杂媒体处理的**多模式代理**
2. 创建**自定义管理器代理**以进行复杂的编排
3. 为混合系统实施**自带代理**
4. 使用**重播任务**进行稳健的错误恢复

## 最佳实践

### 发展
- **从简单开始**：在增加复杂性之前从基本的顺序工作流程开始
- **增量测试**：在集成到更大的系统之前测试每个组件
- **使用注释**：利用 Python 注释来获得更清晰、更易于维护的代码
- **自定义工具**：构建可在不同代理之间共享的可重用工具

### 生产
- **错误处理**：实施强大的错误处理和恢复机制
- **性能**：使用异步执行并优化 LLM 调用以获得更好的性能
- **监控**：集成可观察性工具来跟踪代理绩效
- **人工监督**：包括关键决策的人工检查点

### 优化
- **资源管理**：监控和优化令牌使用和 API 成本
- **工作流程设计**：设计工作流程，最大限度地减少不必要的 LLM 调用
- **工具效率**：创建高效的工具，以最小的开销提供最大的价值
- **迭代改进**：使用反馈和指标不断提高代理绩效
