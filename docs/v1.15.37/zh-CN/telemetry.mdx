## 遥测

<Note>
    默认情况下，我们不会收集任何在 GDPR 及其他隐私法规下可被视为个人信息的数据。
    我们会收集工具名称和 Agent 角色名称，因此请勿在工具名称或 Agent 角色中包含任何个人信息。
	由于不收集个人信息，因此无需担心数据驻留问题。
	当启用 `share_crew` 时，会收集额外数据；如果用户在其中包含个人信息，这些数据可能含有个人信息。
    启用此功能时，用户应谨慎操作，以确保符合隐私法规。
</Note>

CrewAI 使用匿名遥测来收集使用统计信息，主要目标是改进该库。
我们的重点是持续优化并开发用户最常使用的功能、集成和工具。

必须明确的是，默认情况下，关于提示词、任务描述、Agent 背景故事或目标、
工具使用、API 调用、响应、Agent 处理的任何数据，以及密钥和环境变量，**均不会收集任何个人数据**。
启用 `share_crew` 功能后，会收集包括任务描述、Agent 背景故事或目标及其他特定属性在内的详细数据，
以提供更深入的洞察。如果用户已将个人信息纳入其 crew 或任务，此扩展数据收集可能包含个人信息。
用户在启用 `share_crew` 前，应仔细考虑其 crew 与任务中的内容。
用户可将 `CREWAI_DISABLE_TELEMETRY` 设为 `true`、`1`、`yes` 或 `on`（不区分大小写）来禁用 CrewAI 遥测。将 `OTEL_SDK_DISABLED` 设为相同取值也会禁用 CrewAI 的导出器。但 OpenTelemetry SDK 本身在禁用进程中其他埋点时仍只识别 `true`。
AMP 追踪另见 [Tracing](/zh-CN/observability/tracing)。`OTEL_SDK_DISABLED` 不会关闭它：请设置 `CREWAI_TRACING_ENABLED=false`，或在 Crew 或 Flow 上设置 `tracing=False`。

### 示例：
```python
# Disable CrewAI telemetry only
os.environ['CREWAI_DISABLE_TELEMETRY'] = 'true'

# Disable all OpenTelemetry instrumentation, CrewAI's telemetry included (not AMP tracing)
os.environ['OTEL_SDK_DISABLED'] = 'true'
```

`CREWAI_DISABLE_TELEMETRY=1`（或 `yes` / `on`）与 `true` 效果相同。无法识别的取值会被忽略，遥测保持开启。

### 与你自己的 OpenTelemetry 配置隔离

CrewAI 的遥测运行在其私有 `TracerProvider` 上，且绝不会将
自己注册为全局 provider。这使两条链路彼此隔离：

- 进程中其他已埋点库（如 Web 框架、
  数据库客户端、HTTP 客户端）的 spans 永远不会发送到 CrewAI。
- CrewAI 的遥测 spans 也永远不会发送到你的可观测性后端，
  因此不会出现在 Langfuse、Braintrust、Phoenix 或你配置的任何其他采集器中。

可观测性集成不受影响：它们通过各自的 tracer provider 为 CrewAI 添加埋点，
该 provider 与此处描述的 provider 相互独立。

### 独立 Agent 对话

实验性的独立 Agent 对话会发出这些 `Feature Usage` spans。每个 span 计一次发生：

| `feature` | 计数事件 |
| --- | --- |
| `standalone_agent:handle_turn` | 在会话 opt-in 校验通过后，一次公开的 `Agent.handle_turn()` 调用。 |
| `standalone_agent:chat:repl` | 一次用于普通聊天的公开 `Agent.chat()` 调用。 |
| `standalone_agent:chat:tui` | 一次公开 `Agent.chat(tui=True)` 调用。 |
| `standalone_agent:conversation_turn` | 一次已完成的会话式 Agent 回合。 |
| `standalone_agent:conversation_turn_failed` | 一次失败的会话式 Agent 回合。 |

调用计数并不意味着聊天会话一定成功启动。回合结果还覆盖托管的 Agent Flow bridge 与流式回合；现有 Flow 对话计数保持不变。普通 Agent 与普通会话式 Flow 不会发出这些 Agent 专属信号。

这些信号不会附带消息内容、响应、会话 ID、Agent 角色、模型名称或错误文本。它们保留下文列出的通用 Execution Environment 属性。静默模式和禁用 AMP 追踪不会禁用使用遥测。将 `CREWAI_DISABLE_TELEMETRY=true`、`CREWAI_DISABLE_TRACKING=true` 或 `OTEL_SDK_DISABLED=true` 可禁用这些信号。

### 选择加入更多遥测共享

用户可在 crew 配置中将 `share_crew` 属性设为 `True`，选择共享完整遥测数据。
启用 `share_crew` 后，会收集详细的 crew 与任务执行数据，包括任务的 `goal`、`backstory`、`context` 与 `output`。
这有助于更深入地洞察使用模式。

<Warning>
    如果启用 `share_crew`，所收集数据可能包含个人信息（若其已被纳入 crew 配置、任务描述或输出）。
    用户在启用此功能前应仔细审查其数据，并确保符合 GDPR 及其他适用隐私法规。
</Warning>
